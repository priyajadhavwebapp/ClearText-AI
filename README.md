# ClearText — Complex Information Simplifier

A lightweight browser-based prototype based on the problem statement: help people understand complex information, technical terms, and instructions in clear language.

## Features
- Paste text and simplify selected formal/technical phrases.
- Generate key takeaways from the source sentences.
- Detect some terms and show plain-language definitions.
- Suggest practical next steps based on deadlines and required actions.
- Copy the generated explanation.
- Responsive layout for desktop and mobile.
- Runs locally in the browser; no API key, server, or package installation is required.

## Run the project
1. Extract the ZIP file.
2. Open the `ClearText_Information_Simplifier` folder.
3. Double-click `index.html` to open it in a browser.
4. Paste text and click **Simplify information**, or click **Try an example**.

You can also open the folder in VS Code and use the Live Server extension if installed.

## Project files
- `index.html` — application layout
- `style.css` — visual design and responsive styling
- `script.js` — text processing, key takeaways, glossary and copy feature

## Important limitation
This is a front-end demo using rule-based text processing, not a generative AI model. It does not guarantee that the simplified version preserves every nuance. Always verify important legal, medical, financial, or safety information against the original source.
